# Vendored Dais

Presentation framework for the decks in `public/talks/`. Copied here on
purpose rather than installed: a deck presented on a conference stage must not
change because a dependency did.

- Source: https://github.com/Ethan-Arrowood/dais (`@arrowood.dev/dais`)
- Commit: b22777b488c5553fe6efca13b40ab7c3ff29d2e6
- Version: 0.1.1
- Vendored: 2026-08-04

To refresh, copy `dais.css`, `dais.js`, and `themes/midnight.css` from a
newer checkout and update this file. Re-check every deck afterwards.
