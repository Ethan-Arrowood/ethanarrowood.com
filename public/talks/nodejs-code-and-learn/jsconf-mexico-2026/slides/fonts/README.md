# Fonts

Self-hosted so the deck works without a network. Latin subsets from Google
Fonts, downloaded 2026-10-26. Both are licensed under the SIL Open Font
License 1.1; see the `OFL-*.txt` files.

- Chango 400 (`chango-400.woff2`): display headings, as used by JSConf México.
- Poppins 400, 600, 700 (`poppins-*.woff2`): body text.
