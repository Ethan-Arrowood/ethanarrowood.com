Open source is free as in a puppy

The puppy is free.
Feeding, vet visits, and walks are not.

  • No license fee
  • You pay in hosting, updates, security, and time
  • 2:00. Core idea of the talk; take your time.
  • What open source is: code anyone can read, run, and change.
  • Many projects also sell a hosted version. That is the middle path.
  • The bill does not disappear; it moves from a subscription to your team.

AI changed the math

A year ago

No expertise to run it yourself? Buy the SaaS. That support is what you paid for.

Now

AI can help build apps for your business, and help run them.

Rate it like a ski run

  • Buy it. Someone else runs it and supports it.
  • Hosted open source. Pay for hosting, keep the exit door.
  • Run open source yourself, with AI help.
  • Build it yourself.
  • 3:00
  • Harder runs cost less money and more skill. Same as the mountain.
  • Pick the run that matches your skill and what happens if you fall.

Example: your website

  • Squarespace or Wix. Pick a template, they run everything.
  • WordPress.com. Open source, hosted for you.
  • WordPress on your own server. Same software, you run it.
  • Do it all yourself. Write the site, run the server.

  • Every run on one familiar tool.
  • Blue and black are the same software. You can move between them; that's the exit door.

Example: if you are a tech company

Building the tech is the job. The question moves down a layer: who runs the platform under it?

  • Harper Fabric with support. Build on our platform, we run it.
  • Harper Fabric without a support contract.
  • Run Harper yourself. It's open source.
  • No platform. Build and run your whole stack yourself.
