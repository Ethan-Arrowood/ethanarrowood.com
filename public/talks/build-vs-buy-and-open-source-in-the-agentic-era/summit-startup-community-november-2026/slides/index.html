AI changed the math

A year ago

No expertise to run it yourself? Buy the SaaS. That support is what you paid for.

Now

AI can help you run existing software yourself, or build brand new apps.

So do you build from scratch, or start from what someone already built?

What is open source software?

Software whose code is public. Anyone can use it, change it, and run it themselves.

  • LinuxRuns most of the internet's servers
  • AndroidPhones, built on Linux
  • WordPressWebsites and blogs
  • FirefoxWeb browser
  • VLCVideo player
  • Blender3D and animation
  • LibreOfficeDocuments and spreadsheets
  • SignalPrivate messaging

Many also sell a hosted version. WordPress is free to run yourself; WordPress.com runs it for you.

Open source is free as in a puppy

…but food, vet visits, and toys are not

Pay for what you can't afford to lose.

Example: team chat

  • Is your team mostly in person?
  • If chat goes down, can you use email, phones, or a meeting?
  • Can you manage it yourself, with AI help?

Then running your own chat may beat a big Slack bill.

Example: design tools

  • Is design what you sell?
  • If a tool breaks, can the work wait a few days?
  • Can your team learn a new tool, with AI help?

Marketing agency

Design is the business. Keep paying for Adobe and its support.

Marketing is a small part

An open source suite can replace a big Adobe bill.

Example: if you are a tech company

Building the tech is the job. The question moves down a layer: who runs the platform under it?

  1. Harper Fabric with supportBuild on our platform. We run it and provide support.
  2. Harper Fabric without supportWe run it. No support contract.
  3. Run Harper yourselfThe core Harper platform is open source.
  4. No platformBuild and run your whole stack yourself.

Less workMore control
